# Overview

This is a general repository for the project and its related work.

For more details, please refer to the following repositories:

- **Graph Neural Network-Based Evolution and Decision Scheme:** [neGAT](https://github.com/bcozmen/neGAT)
  Explores graph neural network-based approaches to evolutionary strategies and decision-making.
